# Google sujungimas

Kadangi programa daug naudoja „Google Sheets“ API, reikia suteikti jai prieigą. Tai galima padaryti sekant **Authorize credentials for a desktop application** instrukcija svetainėje: <https://developers.google.com/workspace/sheets/api/quickstart/python>

Atsisiuntus, reikėtų sudėti į ```HOME/config/.env/``` aplanka
